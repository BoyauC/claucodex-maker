Signature Pad

簽名板系統

打開網頁即可在下方簽名，完成後可下載 PNG 檔，再上傳到 GitHub repository。

支援滑鼠、觸控筆與手機手指簽名。調整視窗大小時會保留目前簽名。

上傳到 GitHub 的方式

  1. 按「下載簽名 PNG」取得圖片檔。
  2. 進入你的 GitHub repo，例如 BoyauC/claucodex-maker。
  3. 點選 Add file → Upload files，上傳 PNG 後 commit。

注意：瀏覽器前端不能安全地內建 GitHub Token，所以本系統不會把你的權杖寫進程式碼。若要做到「按一下直接寫入 GitHub」，建議加一個後端或 GitHub App 代管授權。
